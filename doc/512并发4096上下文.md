# 512 路、4096 上下文：vLLM 整批快 18%

Qwen3-0.6B，RTX 4090 D，bfloat16。512 条相同请求，每条 prompt 3968 token，再生成 128 token，序列长度正好 4096。两边都是 max_num_seqs=512、max_model_len=4096、单步最多 16384 token、块大小 16、显存占用 0.9、前缀缓存关闭、temperature=0、ignore_eos。吞吐按整批墙钟计算，不含引擎启动。来源：本机实测，2026-10-27。

| 指标 | 数值 |
| --- | --- |
| vLLM 0.15.0 整批完成 | 60.8 s |
| InferFlow 整批完成 | 71.6 s |
| vLLM 相对 InferFlow 的总吞吐 | 1.18× |
| 显存里能同时放下的满 4096 上下文 | 约 40 条 |

## 整批完成时间

从提交这 512 条到全部生成完的秒数。两边输出都是 65536 token。

| | 墙钟时间 |
| --- | ---: |
| InferFlow | 71.59 s |
| vLLM | 60.84 s |

## 按墙钟折算的吞吐

总 token 含 2,031,616 个 prompt token 和 65,536 个输出 token。输出吞吐是输出 token 数除以整批时间，这段时间里也包含 prefill。

| | InferFlow | vLLM |
| --- | ---: | ---: |
| 总 token/s | 29295 | 34468 |
| 输出 token/s | 915 | 1077 |

满 4096 的 KV：InferFlow 划了 178,848 个 token（11,178 块 × 16），大约 44 条；vLLM 划了 161,152 个 token（10,072 块），大约 39 条。日志里 vLLM 同时在跑的请求是 35–40 条，其余在等待。InferFlow 抢占 11 次，vLLM 抢占 14 次。

## 同条件对照

请求用同一组随机 token（种子 0）。启动时间不含在吞吐里。vLLM 跑完后进程退出时引擎报了一次关闭错误，65536 个输出 token 已经全部返回。
